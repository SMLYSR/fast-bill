## 目标
- 为历史流水页面添加与今日流水一致的“向下滑动后顶部悬浮返回顶部”交互，样式与动效保持一致。

## 复用规范
- 样式：复用 `app/(tabs)/index.tsx` 中 `toTop`/`toTopBtn`/`toTopText` 的视觉参数（背景 `#f3f3f3`、圆角 18、内边距 14×8）。
- 动效：淡入淡出使用 `Animated.Value`，时长 300ms；阈值 `contentOffset.y > 160`。
- 行为：点击后调用 `FlatList.scrollToOffset({ offset: 0, animated: true })`。

## 代码改动点
- 文件：`app/history/[date].tsx`
  1) 引入与定义
  - `import CrossPressable from '@/components/CrossPressable'`
  - `const listRef = useRef<FlatList<Transaction>>(null)`
  - `const [showTop, setShowTop] = useState(false)` 与 `const fade = useRef(new Animated.Value(0)).current`
  2) 绑定 `ref` 与滚动事件
  - 给历史页 `FlatList` 设置 `ref={listRef}`
  - 设置 `onScroll={e => { const v = e.nativeEvent.contentOffset.y > 160; setShowTop(v); Animated.timing(fade, { toValue: v ? 1 : 0, duration: 300, useNativeDriver: true }).start(); }}`，`scrollEventThrottle={16}`
  3) 悬浮按钮
  - 在页面根容器中加入：
    ```tsx
    <Animated.View style={[styles.toTop, { opacity: fade }]}> 
      <CrossPressable style={styles.toTopBtn} onPress={() => listRef.current?.scrollToOffset({ offset: 0, animated: true })}>
        <Text style={styles.toTopText}>返回顶部</Text>
      </CrossPressable>
    </Animated.View>
    ```
  4) 样式补充
  - 向 `styles` 增加：
    ```ts
    toTop: { position: 'absolute', top: 8, left: 0, right: 0, alignItems: 'center' },
    toTopBtn: { backgroundColor: '#f3f3f3', borderRadius: 18, paddingHorizontal: 14, paddingVertical: 8 },
    toTopText: { color: '#333' },
    ```

## 兼容与注意
- 与现有进入动效（240ms）不冲突；滚动阈值和样式对齐今日页。
- Web 端悬浮层不影响滚动条样式注入；层级不遮挡 FAB。
- 无数据时依旧显示按钮逻辑不受影响（在滚动到阈值时出现）。

## 测试
- 场景：
  - iPhone/Android：滚动超过 160 显示按钮；点击返回顶部；继续滚动淡出。
  - Web：同样行为；验证按钮层不遮挡其他交互；滚动条样式仍生效。
- 回归：今日页交互保持一致；统计页跳转到历史页后交互正常。
