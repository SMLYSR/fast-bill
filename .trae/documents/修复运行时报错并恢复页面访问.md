## 问题诊断
- 主要错误位于 `app/(tabs)/profile.tsx`：
  - 在组件外部调用 Hook，出现非法 Hook 调用（Invalid hook call）和语法错误：`app/(tabs)/profile.tsx:268`。
  - 样式键散落在 `StyleSheet.create` 之外（`preview`、`previewCard`、`previewText`、`colorChip`），导致编译或运行异常：`app/(tabs)/profile.tsx:269-272`。
  - 代码中使用了 `setThemeBg`，但未从 `usePreferenceStore` 解构，运行时会触发 `ReferenceError`：`app/(tabs)/profile.tsx:206-215`。
- 其余页面与组件经检查未发现会拦截渲染的致命错误；登录页存在重复样式键但不影响运行：`app/(auth)/login.tsx:140-141`。

## 修复方案
1. 将 `const themeTokens = useThemeTokens()` 移入 `ProfileScreen` 函数组件内部，靠前定义，确保在 JSX 使用前可用。
2. 从 `usePreferenceStore` 补充解构 `setThemeBg`：`const { ..., setThemeBg } = usePreferenceStore()`。
3. 将散落的样式键（`preview`、`previewCard`、`previewText`、`colorChip`）并入 `StyleSheet.create({ ... })` 的样式对象，移除文件末尾的多余行。
4. 保留登录页的重复样式键或统一为一份；该项非阻塞，可作为后续清理。
