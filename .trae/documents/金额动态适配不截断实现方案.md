## 目标
- 金额文本在各自区域内自适应显示，不出现截断或省略号。
- Web 与移动端均可读性良好：用户一眼看清数值。

## 现状
- 当前金额文本在 `components/SummaryCard.tsx:16, 21, 26` 使用 `numberOfLines=1` 与省略（web 映射为 CSS `text-overflow: ellipsis`），存在截断风险。
- 标题颜色已调整为灰色：`components/SummaryCard.tsx:37`。

## 改造方案
1. 新增通用组件 `components/FitText.tsx`
   - 作用：根据容器宽度与文本实际宽度计算缩放比例，使文本完整显示在单行内。
   - 实现要点：
     - 父容器与文本分别 `onLayout` 获取 `containerWidth` 与 `textWidth`。
     - 计算 `scale = min(1, (containerWidth * 0.95) / textWidth)`，通过 `style.transform: [{ scale }]` 应用缩放；保证不超出列范围且不省略。
     - 移动端优先使用 `adjustsFontSizeToFit` 作为兜底，设定 `minimumFontScale = 0.8`；Web 使用 `scale`。
     - 颜色、字体粗细等通过 props 透传。

2. SummaryCard 接入 FitText（替换金额 Text）
   - 替换位置：`components/SummaryCard.tsx:16, 21, 26`。
   - 保持原有配色与布局，`col` 宽度通过现有 `flex:1` 与 `gap` 不变。
   - 移除 `numberOfLines/ellipsize`，改为 FitText 单行自适应缩放，不截断。

3. 细节与移动端优化
   - 保持 `textAlign:'center'` 与 `maxWidth:'90%'`（`components/SummaryCard.tsx:41`）以增强左右留白。
   - Android 设置 `includeFontPadding:false`、`allowFontScaling:true`；iOS 保留系统字形渲染，避免断行。
   - 大额显示（位数多）确保缩放至 0.8 时仍完整可读；如超出极端场景，进一步降至 0.7（可配置）。

## 验证

- iOS/Android：金额完整、字号自动缩小但不低于下限；不同屏幕密度下清晰可读。
