## 结论与诊断
- “7 条日志”是 React DOM 的开发期警告：Web 不识别 `onResponder* / onPressOut` 这类 RN 事件；与样式不一致无直接关系。
- 统计页样式未对齐主要因：卡片边距/阴影不统一、日历单元布局与字体间距不匹配、折线卡头部分段/类型切换样式偏差、数值颜色与字号偏小。

## 更新范围
- 仅修改：`app/(tabs)/statistics.tsx` 的样式与少量结构（不改交互逻辑）。
- 警告抑制：保持此前对 Tab 按钮的 Web 包装；额外在统计页中避免把 RN Responder 事件透传到 DOM（使用现有 `CrossPressable` 不传递 responder 属性即可）。

## 统计页 1:1 样式对齐
1. 页面与卡片
- 外层背景改为 `#f5f5f5`；统一左右内边距 16；卡片圆角 24、阴影与间距统一。
- 宽度自适配：`maxW = min(393, width - 32)`，居中。

2. 日历卡片（CalendarCard）
- Header：左右箭头按钮圆形灰底；月份文本居中加粗。
- Week 行：等分 7 列、行高与间距与原型匹配。
- Day 单元：
  - 圆角矩形/圆形容器 `38x38`，背景 `#F9FAFB`，居中数字。
  - 下方每日值文本（`+` 绿 `#34C759`、`-` 红 `#FF3B30`、无数据灰 `#99A1AF`）。
  - 点击态轻微阴影/缩放。

3. 折线图卡片（LineChartCard）
- Period 分段：胶囊外框灰底、内段白底激活有阴影；标签字号与字重调高。
- 收入/支出切换：绿色/红色胶囊按钮；激活态阴影；字号加粗。
- 图表：线粗 `3`、点半径 `6`、虚线网格；颜色随类型；容器圆角与内边距对齐。
- 汇总行：
  - 左列显示当前区间总额，支出用红色、收入时绿色（跟随 `kind`）。
  - 右列显示日均；字号提升。

4. 颜色与字体
- 使用 `Fonts.rounded`（iOS）与当前 Web 默认；颜色值与原型对齐（`#101828, #6A7282, #B6BDC7`）。

## 警告处理策略
- 警告来源与样式无关；保证统计页内不传递 `onResponder*` 到 DOM：继续使用 `CrossPressable`（Web 渲染为 `View + onClick`）。无需额外变更。

## 交付项
- 统一的卡片、日历、折线图样式与数值展示；点击某天仍跳到 `/history/yyyy-mm-dd`。

## 验证
- Web：打开统计页，检查日历单元、折线卡胶囊、汇总色值与字号；点击多天跳转历史页。
- 移动端：iOS/Android 运行，检查阴影/圆角一致性与点击态。
